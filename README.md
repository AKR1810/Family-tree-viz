# What's your mother tongue(s)?

An interactive version of my family-language chart: 147 relatives across three generations, linked to the five languages I speak with them (English, Hindi, Marathi, Telugu, Kannada).

- Rings: generations
- Dot size: how close I am to each person
- Faded line: has passed away
- Bold / light name: talkative / reserved
- Typeface: family branch

Built with D3.js. Colours, typefaces, ring sizes and layout live in the SETTINGS block at the top of the script in `index.html`. The family data is the `PEOPLE` list just below it.
